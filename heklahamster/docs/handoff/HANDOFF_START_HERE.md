# Heklahamster — overlevering til Codex / ChatGPT Work

## Start her
Les `CODEX_MASTERPROMPT.md` og `README.md`, og inspiser `index.html` og alle filer i `assets/`. Behold den lekne, fargerike retningen fra versjon 3, men gjør designet mer særegent og mindre generisk.

## Prioriteter
1. Verifiser at ALLE fire hamsterbilder faktisk vises i produktlisten og på mobil. Bruk lokale assets og robuste relative stier.
2. Bygg en rask mobilførst kjøpsflyt: velg hamster → brodering (maks 20 tegn) → hilsen (tekst, lyd eller video, eventuelt hopp over) → mottaker/levering → sikker betaling. Ett tydelig valg per steg, tydelig tilbakeknapp, progresjon og fast CTA.
3. QR-kode til privat hilsen, med tilfeldig sikker lenke, valgfri avsløring av avsender, og rutiner for misbruk og sletting.
4. Ingen fiktive betalinger, priser, anmeldelser eller lagerbeholdning. Merk demo tydelig.
5. Legg grunnlag for produktfeed, strukturerte data og AI-assistert bestillingskladd med eksplisitt betalingsbekreftelse.
6. Legg inn test av mobilvisning, bildebaner, validering og bestillingsflyt.

## Status
Eksisterende HTML er prototype, ikke produksjonsklar butikk. Backend, checkout, QR og opplasting er ikke ferdig integrert. Produktbildene er AI-genererte konseptbilder og må erstattes med godkjente bilder av faktiske varer før salg.

## Arbeidsmetode
Ta utgangspunkt i eksisterende filer. Opprett Git-repo eller ny gren etter behov. Dokumenter endringer, manglende nøkler og deployinstruksjoner. Ikke publiser eller aktiver ekte betaling uten eksplisitt godkjenning.
