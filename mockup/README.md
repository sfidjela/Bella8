# Skjermer — mockup

Fem mobilskjermer (390×844) for meldingstråden og minne-siden.

| Fil | Skjerm |
|---|---|
| `Main.dc.html` | Innslipp — hun sender skjermbilde av barnehagemeldingen |
| `Hendelse.dc.html` | Hendelseskortet med «Legg i kalenderen» |
| `Morgen.dc.html` | Morgenmeldingen kl. 07.02 — dagens tre ting |
| `Minne.dc.html` | «Det jeg vet om dere» — barn, faste ting, slett alt |
| `Del.dc.html` | Del med partner — hun sender meldingen selv |
| `canvas.json` | Plassering av skjermene på lerretet |

## Standpunkter tegnet inn

- **Ingen egen app.** Alt utenom minne-siden ligger i en meldingstråd.
- **Den foreslår, hun godkjenner.** Skjerm 2 har en knapp. Hvis vi velger at den skriver rett i kalenderen, må skjerm 2 og 3 tegnes om.
- **Ordene AI, bot, assistent og automatisering finnes ikke i grensesnittet** — samme regel som i `lansering/02-landingstekst.md`.
