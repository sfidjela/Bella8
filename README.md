# Familiens ro — lanseringspakke

Ferdig tekst og operativt materiell for pilotlanseringen mot norske mødre (Instagram, mental load-segmentet).

Målgruppe er låst: mødre 30–45, Oslo/Asker/Bærum/Stavanger/Bergen, betaler for **ro** — ikke for «AI».

|---|---|

| [lansering/02-landingstekst.md](lansering/02-landingstekst.md) | Ferdig landingstekst, seksjon for seksjon — klar til å limes inn i Framer/Carrd |

| [lansering/06-7-dagers-plan.md](lansering/06-7-dagers-plan.md) | Hva som skjer dag for dag, budsjett og stoppkriterier |

## To ting må låses før noe publiseres

1. **Navn** — teksten bruker «Familiens ro» som arbeidsnavn. Søk/erstatt når navnet er valgt.
2. **Pris** — teksten bruker kr 1 490/mnd og kr 3 990/3 mnd.

## Ingenting her er sendt

Alt materiell er utkast. Ingen annonser er opprettet, ingen DM-er sendt, ingen kontoer kontaktet.

## Sannhetsregelen

Ingen kundesitater, tall eller «X familier bruker det» før det faktisk finnes.
Alle slike felt er merket `[VENTER]` i teksten og skal stå tomme til en ekte pilotmor har sagt ja til å bli sitert.
